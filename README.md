# 📘 Guia para Tutores - Atividade Síncrona 5

O **Guia para Tutores - Atividade Síncrona 5** é uma aplicação web desenvolvida para apoiar a formação e a atuação de tutores na condução de encontros síncronos sobre **Recursos Educacionais Digitais (REDs)**. O site organiza, de forma clara e navegável, fundamentos teóricos, etapas metodológicas, dinâmicas da atividade, orientações práticas e instrumentos de apoio ao acompanhamento dos cursistas.

## ✨ Funcionalidades

- Estruturação do conteúdo em seções temáticas
- Navegação fixa com rolagem suave entre tópicos
- Destaque automático da seção ativa no menu
- Animações de entrada ao visualizar os blocos de conteúdo
- Tabelas informativas para apoio metodológico
- Layout responsivo para diferentes tamanhos de tela
- Exibição automática da data de geração no rodapé
- Organização visual clara para leitura prolongada

## 📚 Conteúdo abordado

O guia apresenta informações sobre:

- apresentação da atividade síncrona;
- contextualização da jornada de Recursos Educacionais Digitais;
- fundamentação teórica sobre REDs;
- papel do tutor no processo formativo;
- etapas da metodologia da jornada de REDs;
- dinâmica do encontro síncrono;
- atividade de checkout;
- recomendações finais para condução pedagógica.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

## 🎯 Objetivo do Projeto

O projeto foi criado para oferecer um material digital de apoio à mediação pedagógica, ajudando tutores a compreender e conduzir a **Atividade Síncrona 5** com maior clareza, organização e segurança. A proposta é transformar um conteúdo textual extenso em uma experiência de consulta mais acessível, fluida e visualmente estruturada.

## 🧩 Estrutura da Página

A interface está organizada em seções principais:

- **Apresentação**
- **Teoria**
- **O Tutor**
- **Metodologia**
- **Dinâmica**
- **Checkout**
- **Conclusão**

Cada seção reúne explicações detalhadas, listas orientadoras e tabelas de apoio para facilitar a compreensão e a aplicação prática do conteúdo.

## ▶️ Como usar

1. Abra o arquivo HTML em um navegador.
2. Utilize o menu superior para navegar pelas seções.
3. Leia os conteúdos de forma sequencial ou consulte apenas os tópicos desejados.
4. Use o material como apoio para preparação e condução de encontros formativos.

## 🎨 Interface

O projeto utiliza uma identidade visual baseada em uma paleta institucional com:

- fundo claro para leitura confortável;
- destaques em azul, vermelho e amarelo;
- menu fixo no topo da página;
- seções com contraste alternado;
- tabelas organizadas para leitura rápida;
- animações discretas de transição.

## 📱 Responsividade

A página foi adaptada para funcionar em:

- computadores
- tablets
- dispositivos móveis

A navegação permanece acessível em telas menores com rolagem horizontal no menu superior.

## 📁 Estrutura do Projeto

O projeto está concentrado em um único arquivo HTML contendo:

- **HTML**: marcação e organização do conteúdo
- **CSS**: estilo visual, tipografia, responsividade e animações
- **JavaScript**: scrollspy, animação de seções e data dinâmica no rodapé

## ✅ Possíveis usos

Este projeto pode ser utilizado como:

- material de apoio para tutores;
- guia digital de formação;
- página institucional de orientação pedagógica;
- base para outros conteúdos interativos educacionais.
